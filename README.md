# SkillScreen project page

**High-Recall Screening of Malicious Agent Skills with Decision Models**

Website: https://jerroldh.github.io/SkillScreen-webpage/

Research repository: https://github.com/JerroldH/SkillScreen

Static HTML, CSS and JavaScript. No build step or server backend.

## Local preview

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Open http://127.0.0.1:4173. The method animation is illustrative. Results compare matched 99% test recall on SBR, MSD and SD.

## Updates

Edit index.html, style.css, app.js or evidence.js. Downloadable numbers are in assets/results.csv. Commit and push to main to update GitHub Pages.

The Paper link stays inactive until a publication link is available. The Model link opens SkillScreen-2B-SBR. Other checkpoints are grouped at https://huggingface.co/SkillScreen.
